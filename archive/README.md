# Archived material

`historical_docs/` contains superseded phase reports, audits, early method assessments and implementation notes retained for project history and auditability. Some describe prior research directions or corrected/contradictory interim findings; they are not the final v4 methodology or primary result. The local working copy retains historical outputs, but the public release omits third-party trace data and the associated Phase 3–3.3 output folders pending verification of redistribution terms. See [`PUBLICATION_NOTES.md`](../docs/PUBLICATION_NOTES.md).

Use the canonical final methodology and results in `docs/` and `results/research_alignment_v4_final_confirmation/`. The original project title and historical source notes are retained in the archived files.
